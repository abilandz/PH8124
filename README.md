**Last update**: 20260323

This webpage contains the lecturing material for the course PH8124, 'Scientific computing in high-energy physics', offered in SS2026.

The material covered in the previous year is at [SS2025]( https://abilandz.gitbook.io/ss2025 ) (the current semester is based on it, only minor modifications are foreseen).

The formal course description can be found at the TUM website at the following internal [link]( https://app.srv.nat.tum.de/mhb/description?id=17361 ), and at the following public [link]( https://academics.nat.tum.de/en/studies/org/mh/details/mod/PH8124 ).

For **ROOT**, the official documentation is used:

* Overview of all tutorials: [https://root.cern/manual/](https://root.cern/manual/)

* Primer (for beginners): [https://root.cern/primer/](https://root.cern/primer/) (or [pdf](https://cernbox.cern.ch/index.php/s/bmbmbqUMA1keZCH) version)

* Users Guide (last update 2018, not maintained anymore): [html](https://root.cern.ch/root/htmldoc/guides/users-guide/ROOTUsersGuide.html) or [pdf](https://cernbox.cern.ch/index.php/s/N4k9AQ8LtCFWQIc) version
